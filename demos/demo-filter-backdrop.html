drop-shadow sigue la silueta

box-shadow dibuja la sombra del rectángulo invisible de la caja. drop-shadow() dibuja la de lo que realmente se ve.

Un uso real: la Pokédex

Toque una criatura para marcarla como capturada. Las que faltan se ven en gris con grayscale(1) sobre la misma imagen a color. No existe una segunda versión en blanco y negro.

.card img { transition: filter .25s; }
.card[aria-pressed="false"] img {
  filter: grayscale(1);
}

backdrop-filter: difumina lo de atrás

filter difumina el elemento. backdrop-filter difumina lo que está detrás de él. Para que se note, el elemento necesita un fondo semitransparente. Mueva el control y mire las franjas detrás del vidrio.

8px
Vidrio esmeriladoLas franjas de atrás se difuminan. El texto de este cuadro no.
.glass {
  background: rgb(255 255 255 / .35);
  backdrop-filter: blur(8px);
}

Lo mismo en el ::backdrop

<dialog> y popover tienen su propia capa de fondo, ::backdrop. Ahí va el efecto. Abra cada uno y mire esta página detrás.

dialog::backdrop,
[popover]::backdrop {
  background: rgb(20 24 40 / .2);
  backdrop-filter: blur(6px);
}
